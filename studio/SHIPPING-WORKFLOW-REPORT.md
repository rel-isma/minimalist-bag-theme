# Multi-country Shipping workspace — 25 October 2026

Implemented a dedicated Shipping page and links from Launch and the product Fulfillment editor. US is no longer hardcoded as the only launch destination. The user selects the countries; no additional live destination has been enabled by this work.

The app prepares up to 20 countries per saved product, loads actual CJ warehouse areas and the authorized CJ Shopify location, and checks each variant individually. Common-method intersection ensures a method covers all saved variants; each quote represents one item, with variant prices and CJ delivery estimates visible. Successful US/Canada live read tests on Lune found 29/16 common methods across its three variants. The temporary local test country list was restored and listing defaults remained unchanged. CJ rate limiting encountered during testing led to a bounded retry for read-only freight calls only.

Country methods are explicitly local preferences; they do not constitute automatic per-country CJ order routing. One reviewed country can become the local initial native listing default. The existing CJ product/variant connections and inventory setup are not rewritten by this editor.

The Shopify checkout panel can read paginated delivery profiles, CJ location groups, zones, flat/carrier/conditional methods and current country-market conditions. It can save a local customer-rate draft and prepare a reviewed create/update of a USD flat rate. A new country zone adds only that country; a selected rate update preserves the zone's existing coverage and other rates. Shared-country zones, overlapping country/province zones, conditional methods and carrier-calculated methods are not automatically rewritten. Shared-profile impact is shown before a one-use 15-minute confirmation plan; current profile fingerprint and granted permissions are checked again before mutation, then the saved rate is read back.
